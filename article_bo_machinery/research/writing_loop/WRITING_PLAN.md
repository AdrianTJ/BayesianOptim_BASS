# Writing loop for the machinery-confound article

**Goal:** Take `article_bo_machinery/main.tex` from scaffold (section outlines
+ `% TODO` blocks + preliminary numbers) to a submission-ready draft whose
every empirical claim traces to `final_results/`, applying the working principles
adopted for this project's loops: single-writer prose, read-only fan-out,
worker/verifier split, deterministic checks, durable logs.

**State:** This file is the plan; `WRITING_LOG.md` is the append-only cycle
record whose latest "Next:" line is the resume instruction for a
fresh-context cycle. All research/compute outputs are markdown; the article
itself stays LaTeX (the deliverable format), with its status tracked here.

---

## How the researched principles shape this loop

| Principle | Design decision here |
|---|---|
| Fan-out fails on write-heavy shared state; prose needs one owner | **Single writer:** exactly one agent/session edits `main.tex` per cycle. Subagents never touch the TeX. |
| Fan-out pays for read-heavy decomposable work | Subagents (Sonnet 5) do only reads: numbers extraction, source verification, claim–data consistency sweeps, adversarial section reviews. |
| Self-graded exit checks get reward-hacked; split worker/verifier | The cycle that writes a section never approves it. Every drafted section gets an independent review pass (different agent, or Fable 5 reviewing Sonnet legwork) before its TODO is marked resolved. |
| Deterministic scripts own the execution graph | Mechanical checks live in `tools/check_article.py`, not in model judgment: citation integrity, TODO ratchet, tagged-number consistency. |
| Fresh context per cycle + durable artifacts | Each cycle reconstructs state from `WRITING_LOG.md` + git history. Log entries end with a "Next:" a zero-context session could execute. |
| Explicit task boundaries prevent duplicated fan-out work | Every subagent brief states what is *out* of scope. Section assignments below are disjoint. |
| Stall counter | Two consecutive cycles with no committed change stop the loop and report to the user. |
| No silent caps | Anything skipped for budget/scope is logged, never dropped silently. |

## Phase 0 — Ground truth first (blocks everything else)

The scaffold's numbers are PRELIMINARY (10–15 seeds) and one headline claim
is now **contradicted** by the final 25-seed run: the scaffold's
"Consequences" section says repaired machinery moved BASS-BO to parity on
Func-2C (5W/5L); `final_results/` + `code_files/3_categorical_diagnostics/README.md`
show BASS-BO still **lost** Func-2C 5W/2T/18L (p=0.043) and Func-3C 8W/3T/14L
while GP-BO and TPE won through the identical loop. The honest story got
*stronger* for the machinery thesis (the audit exonerated the machinery and
localized the failure to the surrogate) but the "ranking flip" punchline must
be recast, consistent with the thesis Conclusions.

**P0 deliverable:** `numbers.md` — the canonical numbers file, generated by a
deterministic script (`tools/extract_numbers.py`) from `final_results/*.csv`
and the diagnostics README: per-benchmark optima, paired win/tie/loss +
Wilcoxon p-values, oracle-ceiling A/B results, revisit counts, Spearman fit
quality, budgets/seeds. Every number that appears in the article must appear
here first; the preliminary numbers in the scaffold are replaced, never mixed.

sections per cycle, each cycle = draft → independent review → revise → tests
→ log → commit.

## Phase 2 — Adversarial full-pass review

After S1–S8: fan out read-only reviewers with disjoint lenses — (a) every
number in the TeX vs. `numbers.md`; (b) every citation's claim vs. the
novelty-check assessments; (c) internal consistency with the thesis's
Conclusions (the two documents must not contradict each other); (d) argument
holes a hostile referee would attack. Findings go to
`review_findings.md`; the next writer cycles fix them. Loop until a review
pass comes back empty (loop-until-dry, K=1 full clean pass).

## Testing leg (every cycle)

`tools/check_article.py`, deterministic:
1. Every `\cite{key}` in `main.tex` resolves in `references.bib`, and no
   unused bib entries (warning, not failure).
2. **TODO ratchet:** count of `% TODO` markers must never increase; current
   count is recorded in the log each cycle.
3. **Number tagging:** every statistic in the TeX wrapped in
   `\num{...}`-style tags (or listed in `numbers.md`'s checklist section)
   matches `numbers.md`; flags any digit-bearing claim not traceable.
4. Balanced environments / no `\ref` to undefined labels (regex-level).
5. `check_research.py` still passes for the research folder.

LaTeX cannot be compiled here (no TeX toolchain) — compile checks are
explicitly deferred to the user's machine; the log notes this every time the
TeX changes, so it is never mistaken for verified-compiling.

## Cycle template

1. Read `WRITING_LOG.md` tail → pick up "Next:".
2. Read-only subagent legwork if the section needs it (disjoint briefs).
3. Single-writer drafting in `main.tex` (+ markdown decision notes here).
4. Independent review of the drafted section; revise.
5. Run `tools/check_article.py` + `check_research.py`.
6. Append log entry (files touched, TODO count, tests, Next:), commit, push.

## Stop conditions

- Phase 2 review returns a clean pass → final log entry, report to user with
  the compile-and-read checklist for their machine → stop.
- Stall counter: 2 consecutive cycles with no committed change → stop and
  report.
- Anything requiring a decision only the author can make (title, co-authors,
  acknowledgments, submission venue) is queued in the log under "User
  decisions", never guessed at unattended.
